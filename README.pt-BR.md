\## Sobre



O \*\*Matrix Code\*\* é um assistente de programação com IA para terminal, baseado no projeto open-source OpenCode.



Ele mantém compatibilidade com o ecossistema original, mas adiciona identidade própria, melhorias de fluxo de trabalho e funcionalidades adicionais.



\## Funcionalidades



\- Interface própria Matrix Code

\- Identidade visual personalizada

\- Programação assistida por IA

\- Suporte a múltiplos modelos e providers

\- Suporte a MCP

\- Agentes e skills

\- Gestão de contexto

\- Entrada de voz integrada

\- Transcrição de voz em português

\- Voz e teclado no mesmo prompt

\- Edição portátil para Windows em desenvolvimento



\## Entrada por voz



O Matrix Code permite usar voz diretamente dentro do terminal.



Pressione `F8` uma vez para começar a falar.



Pressione `F8` novamente para parar e transcrever.



O texto reconhecido é colocado diretamente no prompt atual.



Ele \*\*não é enviado automaticamente\*\*.



Você pode continuar escrevendo, falar novamente, editar o texto e pressionar Enter apenas quando estiver pronto.



\## Atalho na tela



Na própria interface do Matrix Code aparece:



`F8 voice`



E a instrução:



`F8: speak • F8 again: transcribe • Enter: send`

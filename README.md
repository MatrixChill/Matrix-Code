## About

**Matrix Code** is a customized terminal-based AI coding assistant.

It is built on top of the open-source OpenCode project while adding its own branding,
workflow improvements and integrated features.

The goal is to provide a fast, practical and portable coding environment with a
distinct Matrix Code experience.

## Features

- Matrix Code terminal interface
- Custom Matrix visual identity
- AI-assisted coding
- Multiple model and provider support
- MCP support
- Agents and skills
- Context management
- Integrated voice input
- Portuguese speech transcription
- Keyboard and voice in the same prompt
- Portable Windows edition in development

## Voice Input

Matrix Code includes voice input directly inside the terminal.

Press:

`F8`

to start listening.

Press:

`F8`

again to stop and transcribe.

The recognized text is inserted directly into the current prompt.

It is **not sent automatically**.

You can:

- continue typing
- speak again
- edit the transcription
- combine keyboard and voice input
- press Enter only when the prompt is ready

# Matrix Code v1.3.2

## Changelog curto

- Corrige Ctrl+C no Windows para interromper a sessão sem encerrar indevidamente o TUI.
- Corrige Ctrl+V, Ctrl+Shift+V e Shift+Insert, inclusive no diálogo mascarado de API key.
- Preserva o Console Host/Windows Terminal ao iniciar manualmente por `matrix.ps1`.
- Torna o launcher mais seguro e previsível para OmniRoute e Matrix API.
- Inclui Matrix Voice corretamente no Windows Portable por um build PyInstaller reproduzível.
- Mantém o catálogo dinâmico do OmniRoute e o status de routing já presentes nesta linha de versão.

## Changelog detalhado

### Keyboard e secrets

- Ctrl+C com prompt vazio e sessão ativa dispara interrupt; seleção continua pertencendo ao fluxo de cópia.
- Ctrl+V usa clipboard quando o terminal não entrega bytes de paste e evita inserção duplicada em eventos sobrepostos.
- Ctrl+Shift+V e Shift+Insert seguem o mesmo fallback.
- O diálogo secreto preserva maiúsculas e símbolos pelo `event.sequence`, mantém a máscara e nunca copia o segredo ao cancelar.

### Launcher Windows

- A execução manual de `matrix.ps1` mantém o `matrix.exe` no console atual, evitando um novo Console Host com outro perfil visual.
- `matrix.cmd` mantém o PowerShell auxiliar oculto e abre apenas o TUI visível; prefere `pwsh.exe` quando disponível e mantém `powershell.exe` como fallback, sem flags de ExecutionPolicy.
- Probes de conexão recusada funcionam sob StrictMode no Windows PowerShell e PowerShell 7.
- OmniRoute aceita executável, runtime Node vendorizado e shims globais `.exe`, `.ps1`, `.cmd` e `.bat`.
- O probe-first reutiliza o listener existente e evita duplicação no warm-start.
- Para shims, o launcher aguarda o endpoint, identifica o listener pela porta e command line e rastreia o supervisor OmniRoute real para cleanup dirigido.
- Matrix API usa 20260, credencial DPAPI por usuário, reuse e cleanup apenas dos processos iniciados pelo launcher.

### Matrix Voice e portable

- O build cria um venv isolado, instala dependências fixadas, baixa `Systran/faster-whisper-base` e empacota `matrix-voice-helper.exe` com PyInstaller.
- Os smokes do launcher usam cópia descartável, impedindo que `.matrix`, credenciais, PIDs ou logs contaminem o candidato.
- O ZIP final foi auditado sem arquivos proibidos, segredos reais ou caminhos pessoais.

### Model discovery

- `MatrixCatalog.fromGatewayModels()` transforma o catálogo live do OmniRoute em candidatos roteáveis.
- O status distingue catálogo `live`/`built-in`, reporta `totalModels` e mantém health honesto.

## Instruções para um amigo

1. Extraia `Matrix-Code-Windows-x64-Portable.zip` em uma pasta gravável.
2. Abra PowerShell ou Windows Terminal nessa pasta.
3. Execute `& .\matrix.ps1`.
4. No primeiro uso, cole a OpenRouter API key quando solicitada. Ela é armazenada somente em `.matrix\state\openrouter-api.cred`, protegida por DPAPI para o usuário atual.
5. Valide Ctrl+V, Ctrl+Shift+V, Shift+Insert e Ctrl+C no TUI.
